# `histra` package

Python package containing model types, HRX/SQLite I/O, preprocessing, nonlinear
solver components, postprocessing, tools, and tests.

Project-level usage and status are documented in the repository
[`README.md`](../README.md) and [`docs/README.md`](../docs/README.md).

Historical audit reports and generated metrics are intentionally kept outside
the import package under `docs/archive/`.
